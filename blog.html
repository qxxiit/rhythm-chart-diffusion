1. Introduction

4월.

UGRP를 해야겠다는 생각에 주제를 찾기 시작. 당시 동아리 활동을 위한 악보를 만들고 있어서, 처음엔 악보를 만들어주는 인공지능을 떠올렸다. 다만 조금 알아보니 만만치 않아 보였다. 마침 2월에 Unity 로 차트 편집기까지 구현된 4-8키 리듬게임을 만들어둔 상태라, 차트 생성 모델로 방향을 좁혔다.

7월.

이때까지만 해도 아는 게 없으니 CNN-LSTM 과 Transformer 기반 선행 모델을 재현하며 경험이나 쌓자는 마인드였다. 그런데 찾아볼수록 재현만 하고 끝내기엔 좀 아쉽다는 생각이 듦. 그러다 기존 접근이 전부 autoregressive 하다는 점이 눈에 들어왔음. 왼쪽에서 오른쪽으로 하나씩 토큰을 뱉는 구조라면 곡 전체를 관통하는 패턴 일관성을 보장하기 힘들 것이다. 그렇다면 sequence 전체를 동시에 다듬는 diffusion 은 어떨까? 지금은 이 "패턴 일관성"을 복사 수준의 반복이 아니라 패턴 명확성과 유형 수준 일관성으로 다시 정의해서 봄 (4.1)

문제는 diffusion 은 일반적으로 연속적인 데이터를 다루는데, 차트는 이산적이다. 물론 연속 공간에서 생성한 뒤 양자화하는 방식도 충분히 가능할 것 같음. 다만 이미지 diffusion 에서 흐릿한 영역이 생기는 것처럼, 경계값 근처에서 애매한 출력이 나와버리면 차트에게는 더 치명적일 것이다. 이미지라면 픽셀 좀 뭉개지는 수준이지만, 차트에서는 노트 타이밍이 밀리거나 롱노트가 겹치는 상황이 일어날 수 있기 때문. 양자화 손실을 줄이고 사후처리를 해도 양자화 과정으로 발생한 손실은 0이 될 수 없다.

이산 공간 디퓨전은 양자화 과정을 거칠 필요가 없기 때문에 양자화 손실이 발생하지 않는다.

그렇다면 자연스럽게 떠오르는 다음 질문:

연속/이산 공간 중 어느 공간에서 학습이 더 잘되지?
전자가 유리하면 양자화 손실 좀 일어나도 overall quality 는 더 높을 수 있잖아.

신경망은 본질적으로 미분 가능한 연속 함수이므로, 데이터 역시 연속 공간으로 임베딩해서 학습하는 최적화에 유리할 것 같았다.

연속공간 + 양자화 손실 vs. 이산공간 중 어느 방법이 나을까.

 

최근 연구 결과 (SEDD, MDLM) 에 따르면, 문법이 존재하는 이산 데이터에서는 이산 공간에서 직접 학습하는 게 학습 난이도도 쉽고 최종 퀄리티 모두에서 유리하다고 한다. 이유는 대충 다음과 같음:

1. Topological Mismatch: 이산 데이터를 연속 공간에 임베딩하며 데이터 사이의 Artificial Geometry를 강제로 학습하게 된다.

예를 들어 1 = tap, 2 = hold_start, 3 = hold_body 의 경우, tap과 hold_body의 정확한 중간 지점에 hold_start가 존재한다고 학습한다. 이 토큰 사이의 중간값들의 의미를 찾는 모순이 발생하여 Latent Space가 안좋아져버려 최적화를 방해함.

2. 디코더 양자화 단계에서의 손실 --> 최종 퀄리티 급락

3. mask-based discrete token에 대한 CE Loss 학습은 최고다. 안정적이며 스케일링. (AR LLM 과 같은 CE 학습이고, masked diffusion 도 LLaDA (Nie et al., 2025) 에서 8B 까지 스케일됨)

 

무튼 다시 본론으로.

그래서 discrete diffusion. 처음부터 이산 토큰 공간에서 노이즈를 주고 복원하는 방식을 적용해보기로 함.

선행 조사 결과, 연속 diffusion 기반 커뮤니티 프로젝트는 몇개 발견함.

  • MuG Diffusion: Stable Diffusion 을 개조한 리듬게임 차트 생성기 (latent diffusion)
  • osu-dreamer: 오디오로부터 osu! 맵을 생성하는 diffusion 모델
  • osu-diffusion: Transformer backbone 으로 osu! standard 오브젝트 좌표 생성

반면 이산 상태 공간에서의 diffusion을 차트 생성에 적용한 사례는 (내가 찾은 범위에서는) 없었다. (9/24 기준으로도 못 찾음. 제출 직전에 한 번 더 확인할 것)

데이터 구조가 상당히 유사한 symbolic music generation 분야에선 discrete diffusion 연구가 활발히 진행 중인데 (예: Plasser et al., 2023. 2.3), 리듬게임 차트와 접목한 연구는 눈에 띄지 않았음. 아직 많이 시도하지 않은 것인지, 시도했지만 잘 안돼서 안 남은 것인지는 모르겠음. 선례를 찾지 못했다는 점이 이런 연구 프로젝트를 처음 해보는 나에게 살짝 막막하게 다가오기도 하지만, 동시에 모험심을 자극하기도 한다.

2.1 DDPM 구조와 한계

DDPM 3단계:

  • Forward: 데이터에 노이즈를 조금씩 더해 완전한 노이즈로
  • 학습: "한 스텝만 되돌리는 법"을 신경망에 가르침
  • 샘플링: 노이즈에서 시작해 되돌리기를 반복

이산에서 걸리는 지점은 "노이즈를 더한다"의 의미임. 가우시안 노이즈는 값을 조금 밀어내는 연산이라 거리 개념이 있는 공간에서만 성립함. 픽셀 0.73 + 0.01 은 의미가 있지만 tap + 0.01 은 뭔가? tap 과 hold_end 사이에는 값이 없음. 연속 diffusion 의 "조금씩"이 이산 공간에서는 정의되지 않는 것. MuG Diffusion 류가 연속 잠재공간으로 우회하고, 디코딩에서 양자화 손실을 무는 이유가 이것임.

따라서 심볼을 노이즈처럼 "조금씩 망가뜨리는" 다른 방법이 있는가?

2.2 D3PM: 노이즈 = 확률적 상태 점프

값을 밀 수 없으니 확률적으로 다른 상태로 바꿔치기함. 매 스텝 각 토큰이 어떤 확률로 다른 상태로 점프하는 markov chain 이 이산 diffusion 의 forward. "어디로 점프하나"의 규칙표가 Transition Matrix $Q_t$ (V×V, i행 = 현재 상태 i 에서 다음 상태의 분포)이고, D3PM 논문의 절반은 이 내용인듯.

커널(파괴 방식) 한 스텝의 파괴 $x_T$ 의 모습 파괴된 토큰의 겉모습 연속 쪽 대응물
uniform 확률 $\beta_t$ 로 어휘에서 아무 상태나 뽑아 덮어씀 위치마다 균등 랜덤 토큰 원본과 구별 불가 백색노이즈
discretized Gaussian 가까운 값일수록 높은 확률로 점프 (순서형 데이터용) 거의 균등 랜덤 (정상분포가 균등) 원본 근처 값. 원본과 구별 불가 가우시안
absorbing 확률 $\beta_t$ 로 [MASK] 로만 덮어쓰고 거기서 못 나옴 전부 [MASK] [MASK] 백지 (대응물 없음)

discretized Gaussian 은 이웃 값으로만 점프하는 게 아니라 먼 값으로도 작은 확률로 점프함. Transition matrix 가 doubly stochastic 이라 종착점은 uniform 과 같은 균등분포

2.3 왜 absorbing 이 좋은가? (= masked diffusion)

  1. 자기서술적 파괴: 가려진 곳 = 모르는 곳, 안 가려진 곳 = 원본. uniform 에서는 저 tap 이 원본인지 noise인지 몰라서 "어디를 믿을지"부터 추론해야 함. 모델이 의심병 걸려서 멘헤라 터지고 학습 실패
  2. 되돌리기 = 빈칸 채우기: BERT 의 masked LM 과 같은 과제. BERT 는 15% 고정 비율로 한 번, 우리는 0 – 100% 무작위 비율로 배움
  3. Loss가 CE 로 정리됨: ELBO 의 KL 합에서 안 가려진 위치는 0, 가려진 위치는 cross-entropy (4.9)
  4. 부분 채우기는 덤: 임의의 구간을 [MASK] 로 두고 backward 를 돌리면 됨. AR 은 구조적으로 불가능

즉, masked diffusion = 모든 마스킹 비율에서 훈련된 BERT를 추론 때 반복 실행하는 것.

계보: D3PM (Austin et al., 2021, absorbing 커널) → MaskGIT (Chang et al., 2022, 이미지 토큰 반복 언마스킹 · 확신 순 샘플링) → MDLM/SEDD 계열 (2024, 텍스트 정식화. Loss가 [MASK] 위치의 weighted CE로 단순화!!!!!!)

가장 가까운 응용: Plasser et al. (IJCAI 2023). symbolic music 에 absorbing diffusion 을 적용하고 infilling을 보임. 차트는 여기에 오디오 조건이 붙은 버전이라고 볼 수 있음.

어떤 diffusion 이든 답해야 하는 질문은 셋임.

  • (a) $q(x_t \mid x_0)$ 의 닫힌 형태: 학습 때 t 를 뽑으면 $x_t$ 를 스텝 시뮬레이션 없이 한 방에 만들어야 함
  • (b) $q(x_{t-1} \mid x_t, x_0)$: 모델이 흉내 낼 "정답 되돌리기". $x_0$ 를 아는 신의 관점에서만 정확히 계산 가능
  • (c) Loss 의 계산 가능한 형태: ELBO 의 KL 합이 무너져야 함

absorbing 에서는 (a)는 곱셈, (b)는 조건부 비율, (c)는 KL 세 줄로 끝남. 각각 4.7, 4.8, 4.9.

2.5 표기법 메모

  • $p(x \mid y)$: 조건부 확률. y 를 알 때 x 의 분포
  • $x \sim p$: 분포 p 에서 x 를 뽑음. 코드로 x = sample(p)
  • $\propto$: 정규화 상수만 빼고 비례
  • $q$: 우리가 설계해서 완전히 아는 분포들. 파라미터 없음. forward 전부와 "신의 사후분포"가 여기 속함
  • $p_\theta$: 배우는 분포들. θ 는 신경망 가중치 전체(약 687만 개)를 한 글자로 쓴 것. 닫힌 수식이 없고 실체가 곧 네트워크임. "수식으로 못 쓰는 함수를 확률처럼 다룬다"
  • $x_t$ (아래첨자): diffusion 시간 index. $x_0$ = 원본, $x_T$ = 완전 파괴. $x_t$ 단독이면 격자 전체 [384, 4]
  • $x^{(n)}$ (위첨자): 위치 index. 괄호는 거듭제곱과 구별용. $x_t^{(n)}$ = 코드의 x_t[n]
  • $a$: 오디오 log-Mel. 항상 주어짐. q 에는 절대 없고 $p_\theta$ 에만 등장 (파괴는 무조건, 복원은 조건부)
  • $s$: 목표 난이도 (SR, 채보 단위 scalar). a 와 같은 성격의 조건이라 q 에는 없고 $p_\theta$ 에만 등장. 4.7 – 4.9 는 표기를 줄이려고 a 만 적었고, 거기서 a 는 조건 전체 (a, s, b) 로 읽음 (4.4)
  • $b$: 청크의 평균 비트 길이 (ms, = 60000 / BPM). s 와 같은 성격의 조건이라 q 에는 없고 $p_\theta$ 에만 등장. s 는 곡 전체에 하나, b 는 청크마다 다름 (4.4)
  • $\delta_m$: one-hot 분포. $\delta_m(k)$ 는 그 분포를 값 k 에서 읽은 숫자 (k = m 이면 1, 아니면 0)
  • $\mathbb E$: for 루프로 번역해서 읽음. 아래첨자는 "무엇이 랜덤인지"의 목록이고, 학습 루프의 Batch 가 곧 이 기댓값의 몬테카를로 추정
  • KL: ① 항상 0 이상 ② 두 분포가 같을 때만 0 ③ 앞쪽 분포가 one-hot 이면 $-\log$ (뒤쪽이 정답에 준 확률). ②와 ③이 4.9 에서 그대로 쓰임
  • 같은 글자 q 가 인자를 바꿔가며 나옴: $q(x_t \mid x_0)$ (forward 점프 확률) 와 $q(x_{t-1} \mid x_t, x_0)$ (backward 정답) 는 다른 함수. 글자가 아니라 괄호 안 인자가 정체성

핵심 기여: beat-aligned 전처리

hop을 밀리초 고정이 아니라 박자 단위(1/48 beat)로 잡아서 프레임 한 칸이 항상 같은 음악적 길이를 가짐.

120BPM 곡과 205 BPM 곡의 동일한 패턴이 모델 입장에서 같은 모양으로 보이게 됨. 정렬 없이 학습한 ablation 에서는 출력이 시간축으로 밀리고, 밀리는 양이 곡 진행에 따라 변했다고 함.

구조는 spectrogram을 encoder에, chart token을 decoder에 두는 seq2seq Transformer임 (3-layer, 256-dim. 더 키워도 성능이 안 올랐다고 함).

디코더의 cross-attention 이 "지금 쓰려는 이 노트가 음악의 어느 부분에 대응하는가"를 담당.

  • 입력 창: 오디오 4비트를 인코더에, 디코더에는 앞 2비트의 마지막 차트 토큰 7개 + 48차원 난이도 임베딩을 넣어 뒤 2비트를 생성. 이 창을 2비트씩 밀며 곡 끝까지 반복
  • 토큰: 이벤트 하나 = time 토큰 (0-95, 2비트 안의 1/48비트 위치) + action 토큰 (허용 동작 80종 중 하나). 4.6 의 안 C 에 가까운 계열
  • 난이도 조건 있음 (위의 48차원 임베딩)
  • 데이터: osu!mania 4K 채보를 모은 뒤 (14,648 채보), off-beat 변속이 있거나 지나치게 밀집한(비트당 이벤트 25개 초과) 채보를 빼서 6,781 채보 / 2,004곡. 우리는 off-beat 변속을 재원점화로 처리해서 유지함 (4.6)
  • 학습: Adam · lr 2e-4 · batch 32 · 10 epoch · label smoothing 0.02
  • 평가: 노트 시각만 보는 micro-F1 (레인 무시). osu! 데이터에서 84.6% 로 DDC 의 C-LSTM (83.9%) 을 조금 넘김
  • 스스로 밝힌 한계: 파인튜닝해도 DDR 계열 데이터의 저난도(매우 희소한) 채보 생성에서 크게 실패. osu! 데이터에 그런 채보가 드물어서라고 추정함. 우리도 같은 osu!mania 데이터라 이 추정이 그대로 해당할 가능성이 큼. SR 이 낮다고 희소한 건 아니고 (4.5), 필터 표에서 NPS 0.5 미만이 3채보뿐인 것도 같은 방향. 저밀도 쪽 생성 능력은 SR 이 아니라 비트당 노트 수로 따로 확인할 것. 첫 모델에서도 Easy 의 F1 이 가장 낮음 (6장)

class imbalance 를 어떻게 해소했나: 프레임마다 노트 유무를 이진 분류하던 DDC 식 정식화를 버리고, 이벤트 토큰 열을 생성하는 문제로 바꿈. 빈 프레임이 예측 대상에서 아예 사라지므로 불균형도 사라짐. 반대로 우리 격자 표현(안 B)은 고정 길이(R1)를 얻는 대신 이 불균형을 되가져온 셈 (4.6)

한계: Transformer지만, token-by-token autoregressive 생성임. 게다가 차트 문맥이 직전 2비트의 7토큰뿐이라 매우 국소적이어서, 곡 전체 패턴의 일관성은 구조적으로 보기 어려움. 비교할 때는 주의: 우리 청크(32비트)와 문맥 길이 차이가 커서, 두 모델의 ρ 차이에는 "AR vs diffusion" 과 "2비트 vs 32비트 문맥"이 섞여 들어감 → 문맥을 32비트로 늘린 AR (AR-32) 을 같이 돌려서 분리하고, 여유가 있으면 diffusion 쪽 창을 줄인 것 (D-4) 도 봄 (6장 문맥 비교 설계)

4. Method

4.1 Problem

패턴 일관성: AR 생성은 좌측 문맥만 보므로, 뒤에 올 구간과 반복 · 대칭을 맞추기가 구조적으로 어려울 것이라고 봄.

  • 목표는 복사 수준의 반복이 아님 (1절 · 2절이 노트까지 같으면 오히려 노잼). 대신 둘로 나눔
    • 패턴 명확성: 계단 · 트릴 · 잭 같은 패턴이 한 구절 안에서 끊기지 않고 분명하게 이어지는가
    • 유형 수준 일관성: 비슷한 소리에 비슷한 종류의 패턴이 오는가
  • 둘 다 몇 비트에서 몇 마디 안에서 정해지는 성질이라 32비트 창 설계와 맞음. 곡 단위 구조는 향후 과제
  • diffusion 이 유리하다는 건 전제가 아니라 검증할 질문임. AR 은 "다음 레인은 하나 옆" 같은 좌→우 규칙을 잇기 쉽고, masked diffusion 은 한 스텝에 여러 칸을 독립적으로 열어서 패턴 방향이 섞일 수 있음 (4.8). 반대로 트릴이 다운비트 화음으로 떨어지는 것처럼 뒤를 보고 앞을 정해야 하는 곳에서는 diffusion 이 유리할 수 있음. 2×2 비교 (6장) 와 샘플링 실험 (큐 9) 이 이걸 시험함

Controllability: 난이도나 패턴 스타일을 조건으로 주는 장치가 미흡함 (예: "pre-chorus 에 계단 넣어줘").

  • absorbing diffusion 은 부분 채우기(inpainting)가 별도 학습 없이 됨. 청크 안에서 앞뒤 2마디를 남기고 가운데 4마디를 비워 채우는 식이고, 같은 기능으로 청크를 이어 생성함 (4.8)
  • 난이도 s 는 제어 기능이 아니라 조건으로 넣음. ① s 가 없으면 청크마다 다른 난이도 모드를 뽑아서 곡 안에서 난이도가 오르내림 ② 평가 때 정답 채보의 SR 을 주면 F1 · ρ 에서 난이도 몫의 비유일성이 사라짐 ③ baseline (Yi et al.) 과 DDC 도 난이도를 입력으로 받음
  • 템포 b 도 조건으로 넣음. SR 은 초 단위인데 입출력은 박자 정렬이라, 같은 s 라도 빠른 곡은 비트당 노트가 적어야 함 (근거는 4.5)
  • 주장 수위는 낮게 둠: SR 준수는 지표 하나로만 보고 (4.11), classifier-free guidance 는 범위 밖

다중 키: 4 – 8키나 플레이 도중 키가 바뀌는 채보를 한 모델로 다루는 연구는 거의 없지만, 모은 데이터가 4K 뿐이라 이번 범위에서는 뺌.

 

왜 이산 diffusion 인가: 세 접근 비교

  자기회귀 (AR) 연속 latent diffusion 이산 diffusion (본 연구)
방식 토큰을 좌→우로 순차 생성 채보를 연속 잠재공간으로 인코딩한 뒤 연속 diffusion 상태 공간을 그대로 유지. forward = 각 위치를 독립적으로 [MASK] 로 치환
좋은 점 채보에 자연스러운 표현. 다음 토큰에 문법 제약을 걸기 쉽고, 좌→우 규칙을 이어가기 자연스러움 잘 확립된 방법. 이미지 계열 도구 재사용 양자화 없음. 모든 위치가 청크 전체를 보며 동시에 갱신. 문법 제약을 샘플링 단계에 직접 걸 수 있음 (4.8)
한계 좌측 문맥만 참조 → 뒤 구간과의 반복 · 대칭 대응이 어려움. 추론 시간이 길이에 비례 디코딩에서 양자화 손실이 다시 들어옴. 디코딩 전에는 문법 제약을 걸 수 없음 head 가 위치별 독립 분포를 내서 한 스텝에 같이 연 토큰끼리는 상관이 안 잡힘 → 반복 샘플링으로 보정 (4.8). 한 스텝에 많이 열면 패턴 방향이 섞일 수 있음
부분 채우기 구조적으로 불가 (좌→우 분해와 안 맞음) – 별도 학습 없이 지원

문법 위반 (끝 없는 hold_start 등) 은 위치별 독립 샘플링에서도 날 수 있음. 세 방식의 차이는 위반이 "나느냐"가 아니라 제약을 "어디서 걸 수 있느냐"임.

4.2 Approach

우선순위 (9/30): 논문용 비교보다 성능 좋은 생성기가 먼저. 생성 채보를 좋게 만드는 일 (패턴 명확성, 곡 단위 반복, 여분 노트, 칠 수 있는지) 부터 하고, AR baseline 은 보류, ablation 은 채보를 좋게 만드는 방법을 알려 줄 때만 함. 아래 Phase 1 의 AR 설계는 되살릴 때를 위해 남겨 둠.

Phase 0 – 문제 정의 · 수식화 · 데이터 전수 분석: 완료 (4.3 – 4.9).

Phase 1 – 데이터 파이프라인 + AR baseline (AR 은 9/30 부터 보류)

  • 수집 · 파싱 · 전수 통계 · 토크나이저 · 분할 · SR 라벨: 완료 (4.5, 4.6). log-Mel 파이프라인과 오디오 – 토큰 정합 검증: 완료 (4.5)
  • AR-4: Yi et al. 설정을 우리 코드 · 우리 split · 우리 전처리 (재원점화) 로 재구현. 원 코드로 원문 수치 (84.6%) 를 다시 내는 재현은 일정상 미루고, 공개 코드는 참고용
    • 3-layer · 256-dim encoder-decoder. 인코더에 오디오 4비트, 디코더에 앞 2비트의 마지막 7토큰 + 난이도 임베딩을 넣어 뒤 2비트를 생성하고 2비트씩 밈
    • 학습은 원문대로 (Adam · lr 2e-4 · batch 32 · 10 epoch · label smoothing 0.02). 난이도에는 우리 s 와 같은 SR 라벨을, 템포 b 도 같이 줌
  • AR-32: 창만 32비트로 늘린 같은 코드. 오디오 32비트 전체를 인코더에 넣고, 디코더는 창 안의 이전 이벤트를 전부 봄. 추론은 D-32 와 같은 이어 생성 (앞 2마디 prefix, 6마디씩)
    • 원문 time 토큰 (2비트 안 위치 0 – 95) 은 창을 늘리면 못 쓰므로 비트 경계 토큰 + 비트 안 위치 (0 – 47) 로 바꿈 (REMI 식). 비교표의 AR-4 도 같은 표현으로 학습해서 두 AR 의 차이를 창 크기 하나로 줄임
    • 이벤트당 2토큰이라 고밀도 창은 길어짐 → 최대 길이를 정하고 넘는 창 비율부터 셈. 파라미터 수는 D-32 (약 687만) 에 맞춤
  • 평가는 F1 (레인 포함 · 무시). 원문 수치는 레인 무시 micro-F1 이라 그 기준도 같이 봄. 롱노트 구간까지 보는 mAP@tIoU 는 신뢰도 점수 정의부터 필요해서 12월 범위 밖

Phase 2 – Discrete Diffusion (D-32): absorbing forward (4.7), 오디오 조건 Transformer denoiser (4.10), 제약 샘플링과 이어 생성 (4.8). 구현 완료. 서브셋과 전체 train 으로 학습 · 평가, 샘플링 기본값 확정 (6장). 데이터셋 밖의 새 곡으로도 생성함 (5장). AR 과의 비교는 보류 (위).

Phase 3 – Ablation: 채보를 좋게 만드는 데 답을 주는 것부터 (6장 실험 큐).

Phase 4 – Unity 통합 · 사용자 평가: Unity 통합은 12월 일정상 범위 밖. 사람 평가는 앞당김: 팀 안의 블라인드 플레이 테스트부터 (5장).

4.3 문제 정의와 수식화

교수님 조언대로 구현보다 문제 정의와 수식화를 먼저 함. 정리하려던 일곱 가지와 결론:

  1. 입력 / 출력: 곡 전체가 아니라 청크 단위. 32비트 (4/4 기준 8마디) = 384칸 (4.4)
  2. 토큰화: 비트 격자 칸마다 레인 상태. V = 7, L = 384 (× 4레인). 격자 해상도는 실제 데이터의 정렬률을 보고 d = 12 로 정함 (4.6)
  3. Forward: absorbing state, 선형 스케줄 (4.7)
  4. Reverse: $p_\theta(x_{t-1} \mid x_t, a)$. 조건 (a, s, b) 은 forward 에 없고 $p_\theta$ 에만 들어감 (4.8, 4.10)
  5. Loss: 이산 ELBO → 마스크 위치 cross-entropy (4.9)
  6. 최적화 · 저예산 전략: 초기값을 정하고 학습 루프까지 구현 (4.10, 6장)
  7. 평가: F1 + 구조적 일관성 ρ + 패턴 명확성 (4.11). 이게 제일 중요했음. "diffusion 이 구조적 일관성에 유리할 것"이라는 주장이 측정 방법을 정의하면서 검증 가능한 가설이 됨

전체를 세 문장으로 줄이면 이렇게 됨.

  1. 네트워크는 "가려진 격자 + 음악 + 난이도 + 템포"를 받아 위치별 5클래스 분포를 내는 함수 하나다. 시간은 입력하지 않음. 마스크 비율이 곧 시간 정보라서 (4.10)
  2. 학습은 무작위 비율 γ 로 마스킹한 뒤 가려진 위치의 cross-entropy 를 1/γ 로 가중해 줄이는 것이다 (4.9)
  3. 추론은 그 함수를 T번 호출하며 매번 남은 마스크의 $r_t$ 만큼을 확정하는 것이다. T 와 확정 순서는 추론 때 고름 (4.8)

4.4 입력 · 출력의 형식적 정의

과제: 음악 오디오에 대해 osu!mania 4K 채보 (노트의 시간 · 레인 · 유형) 를 생성한다. 제작자는 곡당 수 시간에서 수십 시간을 쓰므로 제작 단축 · 라이브러리 확장 · 제작 보조 도구로서 가치가 있음.

$$a \in \mathbb R^{Lr \times F}, \quad s \in \mathbb R_{\ge 0}, \quad b \in \mathbb R_{> 0}, \quad x_0 \in \lbrace 0, \dots, 4 \rbrace^{L \times K}, \quad x_t \in \lbrace 0, \dots, 6 \rbrace^{L \times K}$$

학습 목표는 $p(x_0 \mid a, s, b)$, 추론은 $\hat x_0 \sim p_\theta(x_0 \mid a, s, b)$. s 는 목표 SR 로, 학습 때는 그 채보의 SR, 추론 때는 사용자가 정한 값이고 한 곡의 모든 청크에 같은 값을 줌. b 는 청크의 평균 비트 길이 (ms) 로, timing 에서 바로 계산되고 청크마다 다름. s · b 는 a 처럼 forward 에 없어서 4.7 – 4.9 의 유도가 그대로 유지되고, 거기서는 표기를 줄이려고 a 만 적음.

기호 뜻 값
$L$ 청크당 격자 칸 수 (= Transformer 가 보는 시퀀스 길이) 32비트 × 12 = 384
$K$ 레인 수 4
$N = LK$ 위치 (칸, 레인) 수 1,536
$r$ 정렬비 = 칸당 멜 프레임 수 48/12 = 4
$Lr$ 청크당 멜 프레임 수 1,536
$F$ mel bin 수 80
$V$ 어휘 크기 (5 상태 + MASK + PAD) 7
$m$ [MASK] 상태 번호 5
$a$ 오디오 log-Mel (조건, 항상 주어짐) 1536 × 80
$s$ 목표 난이도 SR (조건, 채보 단위 스칼라) 데이터 중앙값 2.94 · 최대 10.07
$b$ 청크 평균 비트 길이 (조건, 청크 단위 스칼라) ms, = 60000 / BPM. 청크 안에 변속이 있으면 평균
$T$, $t$ 샘플링 스텝 수, 시간 색인 학습은 연속시간이라 T 가 없음. 추론 때 고름 (4.9, 큐 9)

두 개의 1536 은 우연임. $N = LK$ 의 4 는 레인 수, $Lr$ 의 4 는 정렬비. 7K 로 가면 N = 2,688 이지만 멜은 그대로 1536 × 80.

회귀가 아니라 생성이라는 점이 중요함. 같은 오디오에 난이도 · 제작자가 다른 채보가 모두 유효하고, 데이터에서도 세트당 평균 3.14개 난이도가 같은 오디오를 공유함. 그래서 F1 은 상한이 낮은 지표임 (4.11). s 를 주면 난이도 몫의 비유일성은 사라지지만 같은 난이도 안의 제작자 · 스타일 몫은 남음.

  • 난이도 · 템포 조건부, 청크 단위 생성. 청크 32비트는 패턴 반복 주기 (4 – 8마디) 를 한 번 이상 담는 길이. 곡당 청크 수 중앙값 11, p95 27

격자의 원점: 레드라인마다 재원점화

  • osu! 메트로놈은 uninherited timing point (레드라인) 마다 리셋되는데, 데이터의 25.00% (4,613곡) 에서 레드라인이 정수 비트에 없음. 곡 처음부터의 누적 비트로 격자를 잡으면 이 곡들에서 격자와 실제 박자가 어긋남
  • 그래서 격자를 구간마다 재원점화함. 구간 i 의 첫 칸 $\sigma_i$ 는 앞 구간 길이 $\Delta_i$ (비트) 로 이어 붙이고, 구간 안에서는 국소 비트 $\ell_i(t)$ 로 셈. $g_i$ 는 구간을 여는 레드라인 시각, $B_i$ 는 beat length
$$\sigma_i = \sigma_{i-1} + \operatorname{round}(d\,\Delta_i), \qquad c(t) = \sigma_i + \operatorname{round}\big(d\,\ell_i(t)\big), \qquad t(c) = g_i + \frac{c - \sigma_i}{d} B_i$$

셀 왕복 커버리지 (d = 12, τ = 5ms) 가 누적 격자 90.81% 에서 재원점화 97.36% 로 오름. 오디오 프레임도 같은 격자 위에 둠 (4.5).

격자 해상도: coverage 표 (전수, 노트 가중)

노트 j 의 시각을 $o_j$, 그 시점의 국소 비트를 $\ell(o_j)$, 구간의 beat length 를 $B(o_j)$ 라 하면, 해상도 d 에서의 스냅 오차는

$$\varepsilon_d(j) = \min_{k \in \mathbb Z} \left\vert \ell(o_j) - \frac{k}{d} \right\vert \cdot B(o_j)$$

이 오차가 허용치 τ 이하인 노트의 비율이 커버리지.

  • 두 격자가 공유하는 건 정확히 1/4 격자 (gcd(12, 16) = 4, 92.80%). 그 밖에서 d = 12 만 담는 셋잇단 계열이 약 4.56%p, d = 16 만 담는 1/8 · 1/16 계열이 약 2.57%p → "1/4 격자 밖에서 셋잇단 계열이 약 1.8배 많다"가 이 발견의 정확한 형태 (양쪽 격자점이 모두 τ 안인 노트는 양쪽에 세므로 근사치)

4.7 Forward process

핵심: 행렬을 곱하지 않는다. 토큰 하나가 스텝 i 에서 살아남을 (안 가려질) 확률이 $1-\beta_i$ 이고 스텝끼리 독립이므로, t 까지 살아남을 확률은 곱임.

$$P(\text{survive to } t) = \prod_{i=1}^{t} (1-\beta_i) \equiv 1-\gamma_t$$

그러면 질문 (a) 의 답인 닫힌 형태가 바로 나옴.

$$q(x_t^{(n)} \mid x_0^{(n)}) = \gamma_t \delta_m + (1-\gamma_t) \delta_{x_0^{(n)}}$$

확률 $\gamma_t$ 로는 [MASK], $1-\gamma_t$ 로는 원본 = 동전 던지기 한 번. 수식 한 줄이 코드 한 줄임. DDPM 에서 $\bar\alpha_t$ 를 얻으려고 가우시안을 합성하던 자리가 곱셈 한 줄로 끝남.

x_t[n] = MASK if rand() < gamma_t else x0[n]
  • Transition matrix 는 $Q_t = (1-\beta_t) I + \beta_t \mathbf 1 e_m^\top$ (MASK 행은 MASK 유지, 즉 흡수) 로 정의만 하고 곱하지 않음. $\bar Q_t = Q_1 \cdots Q_t$ 는 위 한 줄의 일반형일 뿐
  • 스케줄은 $\gamma_t$ 를 먼저 정함. 선형 $\gamma_t = t/T$ (학습 표본의 마스킹 비율이 0 – 100% 균등), 경계는 $\gamma_0 = 0$, $\gamma_T = 1$. $\beta_t$ 는 역산되는 부산물. 실제 학습은 이걸 연속시간으로 보낸 형태 (4.9 끝). 코사인은 큐 6
  • 조건 (a, s, b) 은 forward 에 없음. 파괴는 무조건, 복원만 조건부

Forward 의 두 성질: 포개짐과 독립

t = 0      γ   0%    ·  ●  ·  ·  ●  ·  ●  ·  ·  ●  ●  ·
t = T/3    γ  33%    ·  ●  M  ·  ●  M  ●  ·  M  ●  ●  M
t = 2T/3   γ  67%    ·  M  M  M  ●  M  M  ·  M  M  ●  M
t = T      γ 100%    M  M  M  M  M  M  M  M  M  M  M  M
  • 포개짐 (비가역 = 흡수): 각 행의 마스크 집합이 이전 행의 것을 항상 포함함. 그래서 "정확히 스텝 t 에 가려짐"의 확률이 $\gamma_t - \gamma_{t-1}$ 뺄셈으로 나옴 (4.8 의 $r_t$). uniform 커널에서는 사건이 안 포개져서 이렇게 못 감
  • 독립 (위치별 동전 던지기): 결합분포가 위치별 곱으로 쪼개짐. 4.9 에서 KL 이 위치별 합으로 분해되는 근거이고, head 가 위치별 독립 분포를 내는 것과 짝을 이룸

4.8 Reverse process

언마스킹 비율 $r_t$: 시점 t 에 가려져 있는 토큰 중 정확히 스텝 t 에 가려진 것의 비율. 이게 곧 역방향 한 스텝에서 열 비율임.

$$r_t \equiv \frac{\gamma_t - \gamma_{t-1}}{\gamma_t} = P(\text{masked exactly at } t \mid \text{masked at } t)$$
  • 직관 경로 (포개짐): P(t 까지 가려짐) = $\gamma_t$, P(t−1 까지) = $\gamma_{t-1}$ 이고 사건이 포개져 있으므로 차가 "정확히 t 에". "가려져 있음"을 조건으로 거니까 $\gamma_t$ 로 나눔
  • 베이즈 경로: 분자 = "t−1 까지 생존한 뒤 스텝 t 에 가려짐", 분모 = "t 에 가려져 있음". 두 경로는 $\gamma_t - \gamma_{t-1} = \beta_t (1-\gamma_{t-1})$ 에서 만남
$$q(x_{t-1}^{(n)} = x_0^{(n)} \mid x_t^{(n)} = m, x_0^{(n)}) = \frac{q(x_t = m \mid x_{t-1} = x_0) \cdot q(x_{t-1} = x_0 \mid x_0)}{q(x_t = m \mid x_0)} = \frac{\beta_t (1-\gamma_{t-1})}{\gamma_t}$$

선형 스케줄이면 $r_t = 1/t$. 매 스텝 평균 N/T 개를 열고, $r_1 = 1$ 이라 마지막 스텝에 남은 게 전부 열림 (경계 조건 자동 충족).

신과 모델을 나란히: $x_0$-매개화

가려진 위치에서, $x_0$ 를 아는 신과 모델은 각각

$$q(x_{t-1}^{(n)} = k \mid x_t, x_0) = (1-r_t) \delta_m(k) + r_t \delta_{x_0^{(n)}}(k), \qquad p_\theta(x_{t-1}^{(n)} = k \mid x_t, a) = (1-r_t) \delta_m(k) + r_t \cdot p_\theta(x_0^{(n)} = k \mid x_t, a)$$
  • 확률 $1-r_t$ 로 마스크 유지, $r_t$ 로 언마스킹. 열 때 신은 원본을 쓰고 모델은 자기 예측 분포에서 뽑음. 신의 공식에서 모르는 $\delta_{x_0^{(n)}}$ 자리에 네트워크의 추측을 꽂는 것이 "$x_0$-매개화"의 전부 (일반형 $\sum_{\tilde x_0} q(x_{t-1} \mid x_t, \tilde x_0)\, p_\theta(\tilde x_0 \mid x_t, a)$ 가 absorbing 에서는 위 형태로 줄어듦)
  • 안 가려진 위치는 비가역이라 거꾸로도 확정적: 신도 모델도 $\delta_{x_t^{(n)}}$ → 4.9 에서 이 위치의 KL 이 0
  • 네트워크가 내는 건 $x_0$ 의 분포임. 값을 $p_\theta(x_{t-1} \mid x_t, a)$ 에서 뽑는다고 쓰면 자기 자신을 참조하는 순환이 됨

Constrained Sampling

위치별 독립으로 뽑으면 끝 없는 hold_start 나 시작 없는 hold_body 가 나올 수 있음. 레인 하나의 문법은 이웃한 두 칸의 관계 하나로 끝남 (i 는 같은 레인 안의 칸 번호).

$$x^{(i+1)} \in \lbrace 3, 4 \rbrace \iff x^{(i)} \in \lbrace 2, 3 \rbrace \qquad (2 = \text{start},\ 3 = \text{body},\ 4 = \text{end})$$
  • 롱노트 안 (시작 · 몸통) 다음에는 몸통이나 끝만, 밖 (빈 칸 · 단타 · 끝) 다음에는 빈 칸 · 단타 · 시작만. 위치를 열 때 이미 열린 좌우 이웃과 이 관계가 깨지는 클래스를 0 으로 두고 재정규화
  • 좌우 조건의 교집합은 늘 비어 있지 않고 (왼쪽이 몸통, 오른쪽이 빈 칸이면 {끝}), 가려진 칸이 몇 개 끼어 있든 채울 방법이 있어서 막다른 길이 없음. 같은 스텝의 위치는 레인마다 왼쪽부터 뽑으며 방금 뽑은 이웃도 반영함 (네트워크 호출 추가 없음)
  • 곡의 시작과 끝은 닫힌 경계 (롱노트가 들어오거나 열린 채 끝날 수 없음) 로 두고, 창 중간의 경계는 열어 둬서 다음 창의 고정 문맥이 이어받음
  • 위반율 자체는 제약을 끈 출력에서 잼 (4.11). 제약이 품질을 바꾸는지는 큐 3d

청크 이어 생성

  • 청크를 따로 생성하면 양방향 attention 이 청크 안에서만 돌고, 청크 사이는 오디오로만 이어짐. 그래서 첫 창은 그대로 생성하고, 다음 창은 앞 창의 마지막 2마디 (96칸) 를 고정한 채 나머지 6마디를 채우며 6마디씩 밈
  • 고정 문맥은 역과정 내내 안 가려진 토큰일 뿐이라 추가 학습이 필요 없음 (부분 채우기와 같은 원리). 비용은 독립 생성의 약 1.33배이고, 경계를 넘는 롱노트도 이어짐
  • 한계: 2마디보다 먼 과거는 못 봄. 먼 반복이 살아나는지는 $\rho_{\text{cross}}$ · $\rho_{\text{far}}$ 로 따로 보고 (4.11), 곡 단위 장치는 향후 과제. 독립 생성은 비교 조건 (큐 3c)

4.9 Loss

ELBO 부등식은 Jensen 한 줄

$p_\theta(x_0)$ 는 모든 마스킹 경로 $x_{1:T}$ 에 대한 합이라 직접 계산이 안 됨. 합 안에 $q(x_{1:T} \mid x_0)$ 를 곱하고 나누면 (1 을 곱한 것)

$$\log p_\theta(x_0) = \log \sum_{x_{1:T}} q(x_{1:T} \mid x_0) \frac{p_\theta(x_{0:T})}{q(x_{1:T} \mid x_0)} = \log \mathbb E_q \left[ \frac{p_\theta(x_{0:T})}{q(x_{1:T} \mid x_0)} \right] \ge \mathbb E_q \left[ \log \frac{p_\theta(x_{0:T})}{q(x_{1:T} \mid x_0)} \right]$$
  • log 가 오목이라 평균의 로그 ≥ 로그의 평균 (Jensen). 양변에 −1 을 곱하고 마르코프 성질 + 베이즈로 스텝별로 쪼개면 KL 들의 합이 됨 (DDPM 부록과 같은 대수)
  • 틈은 정확히 계산됨: $-\log p_\theta(x_0 \mid a) = \mathcal L_{VB} - D_{KL}\big( q(x_{1:T} \mid x_0) \Vert p_\theta(x_{1:T} \mid x_0, a) \big)$. 최소화하는 건 NLL 의 upper bound 이지 NLL 자체가 아니고, 둘 사이의 틈은 모델이 forward 를 얼마나 잘 되돌리느냐로 정해짐

 

여섯 단계 사슬

$$-\log p_\theta(x_0 \mid a) \le \mathbb E_q \left[ D_{KL}\big( q(x_T \mid x_0) \ \Vert \ p(x_T) \big) + \sum_{t=2}^{T} D_{KL}\big( q(x_{t-1} \mid x_t, x_0) \ \Vert \ p_\theta(x_{t-1} \mid x_t, a) \big) - \log p_\theta(x_0 \mid x_1, a) \right]$$

세 항을 $\mathcal L_T$, $\mathcal L_{t-1}$, $\mathcal L_0$ 라 하면, $\gamma_T = 1$ 이라 $\mathcal L_T = 0$ (양쪽 다 "전부 MASK"로 확정) 이고, t = 1 에서 $r_1 = 1$ 이라 $\mathcal L_0$ 도 일반식에 흡수됨 → t = 1..T 의 합 하나로 통일.

  1. ELBO: Jensen 으로 NLL 의 upper bound = 스텝별 KL 의 합
  2. 위치 분해: q 의 사후분포도 모델의 역방향도 위치별 곱 → KL 도 위치별 합 $\mathcal L_{t-1} = \sum_{n=1}^{N} D_{KL}\big( q(x_{t-1}^{(n)} \mid x_t, x_0) \Vert p_\theta(x_{t-1}^{(n)} \mid x_t, a) \big)$
  3. 안 가려진 위치: 양쪽 다 $\delta_{x_t^{(n)}}$ → KL = 0 (급소). 이미 드러난 토큰은 신도 모델도 "그대로 둔다"로 일치해서 배울 게 없고, 그 위치의 head 출력은 loss에도 샘플링에도 안 쓰임
  4. 가려진 위치: 아래 세 갈래 계산 → $r_t \cdot (-\log p_\theta(x_0^{(n)} \mid x_t, a))$
  5. 원핫 축약: 신의 분포가 원핫이라 카테고리 KL 이 cross-entropy 가 됨
  6. 몬테카를로: t 에 대한 합을 T × (t 를 균등하게 뽑은 기댓값) 으로 바꾸고 상수 T 는 버림

 

가려진 위치의 KL, 세 갈래

갈래 신이 준 확률 모델이 준 확률 KL 항 이유
k = m $1-r_t$ $1-r_t$ 0 완전히 같음 → log 1 = 0
k = $x_0^{(n)}$ $r_t$ $r_t \cdot p_\theta(x_0^{(n)} \mid x_t, a)$ $r_t \cdot (-\log p_\theta(x_0^{(n)} \mid x_t, a))$ $r_t$ 가 약분되고 $-\log p_\theta$ 만 남음
그 외 0 (무엇이든) 0 신 쪽이 0 이면 항이 죽음 (0 · log 0 = 0)
$$D_{KL}\big( q(x_{t-1}^{(n)} \mid x_t, x_0) \ \Vert \ p_\theta(x_{t-1}^{(n)} \mid x_t, a) \big) = r_t \cdot \big( -\log p_\theta(x_0^{(n)} \mid x_t, a) \big)$$

같은 계산을 안 가려진 위치에 하면 모든 갈래가 0 이라 3번이 따로 증명 없이 나옴. 이 한 줄이 loss 유도의 심장이고, 사슬의 4 · 5번을 동시에 끝냄.

 

최종 loss function과 가중치의 의미

$$\mathcal L = \mathbb E_{t, x_0, x_t} \left[ w_t \sum_{n:\ x_t^{(n)} = m} -\log p_\theta(x_0^{(n)} \mid x_t, a) \right], \qquad w_t = r_t = \frac{1}{t} \quad (\gamma_t = t/T)$$

시점 t 에 가려진 위치는 평균 N·t/T 개라, 1/t 을 곱하면 기댓값이 t 와 무관해짐. 즉 $w_t$ 는 마스크가 많은 시점이 loss를 독식하지 않도록 정확히 상쇄하는 가중치이고, loss는 마스크된 토큰당 평균 CE 를 t 에 대해 균등 평균한 것이 됨. 가중치 1 (D3PM 의 L_simple 계열) 은 마스크가 많은 시점을 더 무겁게 봄 → 큐 7.

 

연속시간 극한: 실제 학습은 이걸로

$$\sum_{t=1}^{T} \frac{1}{t} \, \mathbb E\Big[ \sum_{\text{masked}} \mathrm{CE} \Big] = \sum_{t=1}^{T} \frac{1}{T} \cdot \frac{1}{\gamma_t} \, \mathbb E\Big[ \sum_{\text{masked}} \mathrm{CE} \Big] \ \xrightarrow{T \to \infty} \ \mathcal L_{\text{cont}} = \mathbb E_{\gamma \sim U(0,1)} \left[ \frac{1}{\gamma} \sum_{n:\ x^{(n)} = m} -\log p_\theta(x_0^{(n)} \mid x, a) \right]$$
  • MDLM 의 선형 스케줄 형태와 같음. t 대신 마스크 비율 γ 를 바로 뽑으므로 학습에 T 가 없고, 스텝 수는 추론 때 고르는 값이 됨 (큐 9 가 재학습 없이 돎). 추론은 고른 T 에 대해 이산 유도 그대로 ($r_t = 1/t$)
  • γ 가 0 근처면 1/γ 가 커지므로 배치 안에서 층화 추출 ($\gamma_i = (u + i/B) \bmod 1$) 하고 1e-3 에서 자름. 구현에서는 N = 1,536 으로 나눠 위치당 NLL 상한으로 읽히게 함
# 가려진 위치만, PAD 제외
ce = F.cross_entropy(logits[mask], x0[mask], reduction='sum')
loss = ce / gamma / N

4.10 Denoiser 구조와 학습 설정

$$f_\theta : (x_t, a, s, b) \mapsto \text{logits} \in \mathbb R^{384 \times 4 \times 5}$$

로짓에 softmax 를 걸면 $p_\theta(x_0^{(n)} = k \mid x_t, a, s, b)$. 원본이 MASK · PAD 였을 리 없으므로 head 는 처음부터 5클래스만 냄 (7클래스를 내고 5 · 6 을 −∞ 로 막는 것과 같은 분포). 아키텍처는 이 함수의 내부이고, 마스킹 · 손실 · 샘플링은 이 함수를 어떻게 훈련하고 반복 호출하느냐의 문제라서 따로 봄.

오디오 a  [1536, 80] ─ Conv1D (kernel 4, stride 4) + 위치 임베딩 ─→ 오디오 메모리 [384, 256]
토큰 x_t  [384, 4]   ─ 조회표 (7×64) × 4레인 concat + 위치 임베딩 ──→ h [384, 256]
                       + 오디오 메모리 (칸 i 에 메모리 i 를 더함, 정렬 덧셈)
난이도 s             ─ sinusoidal → MLP ────────────→ [256], 모든 칸에 더함
템포 b               ─ log → sinusoidal → MLP ──────→ [256], 모든 칸에 더함
시간 t               입력하지 않음

h → Transformer 블록 × 6 → [384, 256]
      블록 = self-attn (칸↔칸) → cross-attn (칸→오디오 메모리) → FFN (256 → 1024 → 256)
             pre-LN 잔차, 헤드 4개, PAD 칸은 attention key 에서 뺌
  → LayerNorm → Linear 256 → 20 → 로짓 [384, 4, 5]

입력 표현

  • 오디오: 곡 · 밴드별로 표준화한 log-Mel (4.5)
  • 조회표: 학습되는 행렬 E (7 × 64). 원핫은 모든 상태를 등거리로 둬서 "hold_start 와 hold_body 는 비슷하다"를 못 나타내고, 조회표는 이걸 벡터 거리로 배움. 레인 4개를 이어 붙여 256 (레인 차원을 채널로 사영)
  • 위치 임베딩: 학습되는 P (384 × 256). Transformer 는 입력 순서를 모르므로 몇 번째 칸인지 알려줘야 함
  • 시간은 안 넣음: absorbing 에서는 최적 $x_0$ 예측기가 t 와 무관함 (Ou et al., 2024). 드러난 토큰이 주어지면 가려진 원본의 분포는 데이터의 조건부분포일 뿐이고, t 는 어느 자리가 가려지는지만 바꾸기 때문. 넣어서 확인하는 건 큐 10
  • 난이도 s: SR 에 100 을 곱해 sinusoidal 로 펼친 뒤 MLP (Linear-SiLU-Linear) 를 거쳐 모든 칸에 더함. SR 구간별 조회표는 SR 7+ (0.59%) 같은 희소 구간의 행이 거의 안 배워지고, 연속 인코딩은 이웃 값끼리 통계를 나눠 씀
  • 템포 b: log 를 취한 뒤 같은 구조 (MLP 는 따로). 템포는 비율로 의미를 갖고 (120 → 240 BPM 은 2배), 초당 노트 = 비트당 노트 × 1000 / b 라서 log 에서 곱이 합이 됨. 청크 안 변속은 평균 b 로 근사
  • Conv1D: 커널 · 보폭 4 의 근거는 레인 수가 아니라 칸당 프레임 수 r = 48/12 (7K 로 가도 4). mel bin 80개를 채널로 보고, 겹침 없이 접어서 칸 i ↔ 메모리 i 가 정수로 맞음. 겹치는 kernel 8 은 큐 10

블록과 크기

  • self-attn 은 칸끼리 서로를 조회 (4마디 전 패턴, 같은 칸의 다른 레인), cross-attn 은 칸이 음악을 조회. 잔차 연결이라 초기엔 항등에 가깝고 6층을 쌓아도 그래디언트가 곧게 흐름
  • 6층 · 256차원은 유도가 아니라 예산 선택 ("학습되는 가장 작은 모델부터"). 파라미터 6,869,204개: 블록 6개 632만 (블록당 self 26만 + cross 26만 + FFN 52만) + s · b MLP 각 13만 + 임베딩 · 위치 · conv · 오디오 위치 약 28만 + head 5천

구현하면서 설계와 달라진 점

  • 정렬 덧셈 추가: 오디오 메모리 i 행을 칸 i 에 직접 더함. 칸과 프레임은 구성상 이미 정렬돼 있는데, cross-attn 만으로는 그 대각선부터 새로 배워야 해서 느림. 오디오가 정답을 그대로 담은 장난감 데이터에서도 2층 모델이 cross-attn 만으로는 600 step 뒤 masked CE 0.72, 덧셈을 넣으면 200 step 에 0.09. cross-attn 은 주변 문맥용으로 남기고, 원안 (cross-attn 만) 은 옵션으로 남겨 큐 5 에서 비교
  • 오디오 메모리에도 위치 임베딩을 붙임. 없으면 cross-attn 이 어느 프레임이 어느 칸인지 알 방법이 없음 (파라미터 +9.8만)
  • pre-LN (서브층 안에 LayerNorm) + 마지막 LayerNorm, PAD 칸은 attention key 에서 뺌, 손실은 N 으로 나눔

학습 한 스텝

(x0, a, s, b) ← 청크 하나               # s = 그 채보의 SR, b = 그 청크의 평균 비트 길이
γ ~ U(0, 1)                           # 배치 안에서는 층화 추출
x_t ~ q(x_t | x0)                     # 위치별 독립으로 확률 γ 로 [MASK]
logits ← f_θ(x_t, a, s, b)            # [384, 4, 5]
L ← (1/γ) · Σ_{n: x_t[n]=MASK, ≠PAD} −log softmax(logits[n])[x0[n]]  / N
θ ← AdamW 갱신

최적화: AdamW · lr 3e-4 · warmup 1k + cosine · betas (0.9, 0.98) · wd 0.01 · grad clip 1.0 · CUDA 에서 bf16 · gradient accumulation. 배치는 청크 단위이고 각 청크가 에폭마다 한 번씩 나옴. 검증은 마스크 비율 0.1 · 0.3 · 0.5 · 0.7 · 0.9 에서 고정 마스크로 잰 masked CE 라 런끼리 바로 비교됨. 맥북 (MPS, fp32) 에서 실제 mel 로도 초당 86 – 91청크 (격자 보간을 읽을 때 해도 병목 아님). 서브셋 (28,004청크) 한 epoch 이 5분, 전체 train (218,142청크) 은 한 epoch 약 41분, 6만 step (4.4 epoch) 에 3시간.

4.11 평가

다섯 계층. 모든 지표를 사람 채보와 baseline 에도 똑같이 재도록 처음부터 짬 (같은 격자 위에서 계산). 평가 단위는 곡: val 에서 곡마다 채보 하나 (난이도는 시드로 무작위) 를 뽑아 곡 수 = 표본 수가 되게 하고, 평균에 곡 단위 부트스트랩 95% 신뢰구간을 붙임. 처음 쓴 "val 앞 50채보" 는 13곡의 여러 난이도라 곡 기준 결론이 안 됐음.

1. 노트 정확도

  • F1 @ ±20ms / ±50ms, 레인 포함 · 레인 무시 병기 (레인 무시가 Yi et al. 원문 기준). 매칭은 그리디: 허용치 안의 (생성, 정답) 쌍을 시간 차가 작은 것부터 일대일로 확정
  • 정답이 유일하지 않으므로 F1 은 상한이 낮은 지표임 (4.4). 평가 때는 정답 채보의 SR 을 s 로 줘서 난이도 몫의 비유일성은 없앰
  • 토크나이저 상한을 옆에 같이 적음: 사람 채보를 encode → decode 만 한 것의 F1@20 이 0.9945. 이보다 작은 차이는 양자화 몫
  • 롱노트 구간까지 보는 mAP@tIoU {0.3, 0.5, 0.7} 는 생성 모델의 신뢰도 점수 정의부터 필요해서 미룸

2. 구조적 일관성 ρ (주 지표)

$$\rho = \operatorname{corr}\big( \operatorname{triu}(S^{\text{audio}}),\ \operatorname{triu}(S^{\text{chart}}) \big), \qquad \rho_P = \operatorname{corr}_{(i, j) \in P} \big( S^{\text{audio}}_{ij},\ S^{\text{chart}}_{ij} \big)$$
  • "음악이 반복되는 곳에서 채보도 반복되는가"를 숫자 하나로 본 것. $S$ 는 마디 단위 자기유사도 행렬이고, triu 는 대각을 뺀 위 삼각 (i < j 인 마디 쌍). 대각은 양쪽 다 항상 1 이라 상관을 저절로 끌어올려서 뺌
  • 사람 채보의 ρ 가 기준선. 실측 train 2,110채보 0.215 (in 0.215 · cross 0.202 · far 0.194), val 240곡 0.234. 생각보다 낮고, ρ_in 과 ρ_far 가 거의 같아서 사람 채보의 구조는 창 안보다 곡 전체 (조용한 구간은 조용하게, 센 구간은 세게) 에 걸쳐 있음
  • ρ 는 높을수록 좋은 지표가 아님: 같은 모델에서 샘플링 설정만으로 0.15 – 0.30 을 오가며 사람 수준의 위아래를 넘나듦 (6장). 모델끼리 비교할 때는 샘플링 설정을 고정하고 (무작위 T = 128, 6장), 채보를 다른 곡의 오디오와 짝지은 우연 수준도 같이 봐야 해석이 됨 (우연 수준은 아직)
  • 마디 = 48칸 (row 0 이 마디 첫 박이라 격자에서 바로 자름). 오디오 벡터는 곡 단위로 표준화한 log-Mel 을 칸마다 평균 낸 것 [48 × 80], 채보 벡터는 onset 칸과 롱노트 칸 [48 × 4 × 2]. 유형 단위 벡터 (패턴 주기별 노트 수, 아래 2b) 도 구현해 뒀고, 어느 쪽을 주 지표로 쓸지는 W4 에 고정. 빈 마디는 빈 마디끼리 유사도 1, 아닌 마디와는 0
  • 쌍 집합 P: $\rho_{\text{in}}$ 은 같은 청크 안의 쌍 (청크 = 곡 앞에서부터 자른 고정 8마디, 사람 채보 · AR 에도 같은 구간. 청크당 28쌍뿐이라 곡 단위로 모아서 계산), $\rho_{\text{cross}}$ 는 서로 다른 청크에 걸친 쌍, $\rho_{\text{far}}$ 는 $j - i \ge k$ 마디인 쌍. 위 삼각 전체의 ρ 가 대표값
  • 12월까지의 주 비교는 $\rho_{\text{in}}$ (D-32 vs AR-32). $\rho_{\text{cross}}$ · $\rho_{\text{far}}$ 는 같이 보고하되 곡 단위 주장에는 쓰지 않음
  • k 는 사람 채보에서 인접 효과가 사라지는 거리. train 사람 채보의 마디 간격별 평균 유사도를 보면, 짝수 · 4의 배수 간격 (2 · 4 · 8 · 16 · 24 · 32마디) 에서 튀는 건 악구 반복이고, 인접 효과는 홀수 간격에서 깨끗하게 보임: 1 → 0.286, 3 → 0.265, 5 → 0.253, 7 → 0.244, 9 → 0.242, 11 → 0.235, 바닥 약 0.226. 바닥과의 차이가 0.01 아래로 내려가는 게 11마디, 0.005 아래는 15마디라서 k 는 12 또는 16 중에서 W4 에 고정
  • 보조 지표 (onset 정합률, 밀도곡선 – 에너지 포락 상관) 는 아직

2b. 패턴 명확성

ρ 는 소리와 채보의 반복 구조를 보지, 패턴이 선명한지는 못 봄. 처음엔 계단 · 트릴 · 점프트릴 · 잭의 이름 목록으로 태깅했는데 사람 채보에서도 노트의 4 – 6% 만 잡혀서, 주기로 다시 정의함.

  • 패턴 = 같은 스냅 (간격 1비트 이하) 에서 반복되는 레인 모티프 (최대 8이벤트). 잭은 주기 1, 트릴 · 점프트릴은 2, 롤은 4, 왕복 계단은 6 인 특수한 경우이고, 이름 없는 반복 (1324 1324) 도 잡힘. 주기는 가장 짧은 것으로 셈
  • 최소 길이는 주기 p 에 대해 max(2p, p + 4) 이벤트 (모티프가 두 번 나오고, 앞을 반복하는 이벤트가 네 개 이상). "두 번 나오면 패턴"만으로는 레인을 무작위로 뽑은 스트림도 40 – 49% 가 패턴이 되고, 이 기준에서는 5 – 18%
  • 세 가지를 잼: 패턴에 속한 onset 비율, run 길이, 끊김 (같은 주기 · 같은 모티프 · 같은 간격의 run 두 개 사이에 이벤트가 딱 하나. 레인이든 타이밍이든 한 노트가 벗어났다가 패턴이 이어진 것)
  • 우연 수준도 채보마다 잼: 같은 리듬 · 같은 화음 크기에서 레인만 무작위로 다시 뽑은 사본의 패턴 비율
  • 목표는 최대가 아니라 같은 등급 사람 채보와 비슷한 수준. 너무 높으면 짧은 구간에서 단조로운 것. 12월까지의 주 비교에 들어감 (D-32 · AR-32 · AR-4, 샘플링 설정)

4. SR 준수

  • SR 오차: $\vert \mathrm{SR}(\hat x_0) - s \vert$ 의 평균. 생성물과 라벨을 같은 로컬 계산기로 재므로 계산기 버전 차이는 없음 (4.5)
  • 바닥: 사람 채보를 encode → decode 만 해도 SR 이 평균 0.004 (p95 0.013) 움직임. 이보다 작은 오차는 해석하지 않음
  • SR 은 여분 노트에 민감함 (노트 5% 증가 → SR +0.45, 6장). SR 오차는 precision · 밀도비와 같이 읽어야 샘플링 노이즈를 조건 실패로 오해하지 않음
  • 등급별로 따로 보고 (SR 7+ 는 외삽 영역. Expert 이상은 test 에 45개 안팎이라 묶거나 신뢰구간을 붙임), BPM 구간별로도 봄. b 가 제대로 작동하면 SR 오차와 BPM 의 상관이 0 근처여야 하고, b 가 없으면 빠른 곡은 SR 이 넘치고 느린 곡은 모자랄 것으로 예상 (큐 3e)
  • 단조성: 한 테스트 곡에 s 를 바꿔 넣었을 때 생성물 SR 이 따라 오르는가. 범위는 그 곡의 BPM 대에서 데이터에 실제로 있는 SR 안으로 제한 (느린 곡에 Expert+ 는 외삽)
  • SR 이 못 보는 쪽 (리듬 복잡도 · 롱노트 · 잭) 은 같은 등급 사람 채보와 스냅 분포 · 롱노트 비율 · 잭 비율을 비교

5. 사람 평가 (설계만. 여유가 있으면 W10 에 파일럿)

  • A/B 선호도, n ≈ 20곡. 게임 학회는 사실상 요구하는 항목
  • 체감 난이도는 같은 s 의 생성 채보와 사람 채보를 짝지어 "어느 쪽이 더 어려운가"로만 물음. 절대 점수는 평가자 실력에 따라 기준이 크게 달라짐 (상향평준화). 평가자 실력을 기록하고 그 근처 등급의 곡을 배정해서, 결과를 실력 구간별로 봄
  • 사람 채보는 SV 를 빼고 OD 를 양쪽 같은 값으로 맞춰 틀어줌. 모델은 SV 를 만들지 않으므로

백지 테스트

유도를 "읽어서 아는 것"과 "덮고 다시 쓸 수 있는 것"은 다르므로, 논문 · 노트 · 검색을 전부 닫고 종이에 90분 동안 forward → reverse → loss 재구성. △ 이하 항목은 재학습하고 1시간 뒤 그 항목만 재시험, 두 번째도 막히면 자연어로 먼저 설명해 봄 (설명이 되면 수식으로, 안 되면 이해가 아직 없는 것).

  1. 기호표와 문제 설정: $a$, $s$, $b$, $x_0$, $x_t$, $x^{(n)}$, N, m, q 와 $p_\theta$ 의 차이, shape
  2. Forward: $\gamma_t$ → $q(x_t \mid x_0)$ 를 행렬 곱 없이. 포개짐 · 독립 두 성질
  3. 사후분포 $q(x_{t-1} \mid x_t, x_0)$: 안 가려진 위치 = 그대로, 가려진 위치 = $(1-r_t) \delta_m + r_t \delta_{x_0}$
  4. $r_t = (\gamma_t - \gamma_{t-1}) / \gamma_t$ 를 포개짐 또는 베이즈로. 선형이면 1/t, $r_1 = 1$
  5. 안 가려진 위치의 KL 이 사라지는 이유를 수식 없이 두 문장으로
  6. 손실 여섯 단계 → 마스크 위치 가중 CE. 세 갈래 KL, $w_t = r_t$ 의 상쇄 의미, 연속시간 극한 (가중치 1/γ)
  7. 샘플링 의사코드와 경계 조건 ($\gamma_0 = 0$, $\gamma_T = 1$, $r_1 = 1$, $\mathcal L_T = 0$). 왜 반복하나 (독립 근사)

4.3 의 세 문장을 남에게 설명할 수 있으면 됨.

4비트 (앞 2비트 문맥 + 2비트 생성) AR-4: Yi et al. 설정 재구현 (큐 1) D-4: 창 축소 diffusion (큐 11, 미룸)

  • 같은 열 (창만 다름) = 문맥 길이 효과, 같은 행 (방식만 다름) = 생성 방식 효과. D-32 vs AR-32 가 "같은 문맥에서 AR vs diffusion" 이라 이것만으로 교란이 풀림. 원래 계획이던 AR-4 vs D-32 는 대각선이라 단독으로는 해석하지 않음
  • 12월 범위는 AR-4 · AR-32 · D-32 세 칸. D-4 는 생성 방식의 효과가 창 크기에 따라 달라지는지 (상호작용) 를 보는 칸이라 없어도 핵심 주장은 섬
  • 공통 조건: 같은 split · 같은 조건 (s, b) · 비슷한 파라미터 수 (약 687만) · 같은 추론 방식 (창 안 고정 문맥 + 슬라이드) · 네 칸 다 문법 제약 (위반율은 끈 출력에서 따로). AR 두 칸은 같은 시간 표현 (4.2)
  • 남는 차이는 표현 (AR 은 이벤트 토큰, diffusion 은 격자). 각 방식에 자연스러운 표현을 쓴 것으로 두고 논문에 명시. 지표는 F1, $\rho_{\text{in}}$, $\rho_{\text{cross}}$, $\rho_{\text{far}}$, 패턴 명확성, 보정 전 문법 위반율

7. Conclusion

진행중.

AR 과의 비교는 보류했고 (9/30), 데이터 · 파이프라인 · 첫 모델에서 나온 사실은 이렇다.

  1. osu!mania 4K ranked 18,452 채보에서는 1/12 격자가 1/16 격자보다 노트를 더 많이 담는다 (97.36% vs 95.37%, τ = 5ms). 두 격자가 공유하는 1/4 격자 (92.80%) 밖만 보면 셋잇단 계열 약 4.56%p vs 1/8 · 1/16 계열 약 2.57%p 이고, Yi et al. 의 빈도표와도 방향이 같음 (4.6)
  2. 같은 SR 등급 안에서 비트당 노트는 BPM 에 거의 반비례함 (log–log 기울기 −0.72 ~ −0.92). 난이도가 초당 노트를, 템포가 비트당 밀도를 정한다는 뜻이라 박자 정렬 모델에 템포 조건이 필요한 근거가 됨 (4.5)
  3. masked diffusion 의 샘플링 설정은 1차 변수임. 정답을 외운 모델로도 무작위 순서는 노트를 5% 더 찍어 SR 을 0.45 올렸고, 실제 오디오로 학습한 모델에서는 순서 · 스텝 수만으로 밀도가 0.81 – 1.16배, ρ 가 0.15 – 0.30 으로 움직임. F1 은 그대로라서 기본값은 밀도비와 SR 오차로 골랐음 (무작위 T = 128, 6장)
  4. 사람 채보에서 엄격한 반복 패턴 (같은 스냅에서 반복되는 레인 모티프) 은 노트의 수 % 뿐이지만, 우연 수준보다는 몇 배 높음 (4.11)
  5. mp3 는 디코더마다 시작점이 최대 25 ms 다르고, osu! 채보는 osu! 의 디코더 (BASS) 기준으로 맞춰져 있음. 같은 규칙으로 디코딩하면 osu! 가 서로 다르게 시작하는 파일 그룹들의 온셋 위치가 1 ms 안에서 맞음 (train 2,000곡, 4.5)
  6. 모델은 오디오로 온셋을 찍지만 (오디오를 빼면 온셋 CE +71 – 79%) 레인 패턴은 우연의 2배 수준 (사람 6.7배) 이고, 학습 데이터를 8배로 늘려도 그대로임. 같은 확장으로 난이도 오차 (0.38 → 0.24) 와 ρ 는 사람 수준에 가까워짐. 박자와 난이도는 되고 패턴은 안 되는 상태라, 생성기로서의 다음 과제도 패턴 명확성임 (6장)
